# AI Companion 2.0

An AI companion app with chat, personal wallet, reminders, and controlled AI actions. Built with Flutter.

## Features
- AI companion chat with custom personalities
- Personal wallet (income/expense tracking, Excel export, statistics)
- Reminders with notifications
- Controlled AI ↔ wallet actions
- Dark/Light mode

## Setup
```bash
flutter pub get
flutter run --dart-define=GEMINI_API_KEY=your_key_here
